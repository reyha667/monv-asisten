# Monv Asisten
Asisten melayang (overlay) + Aksesibilitas untuk Android 8.0+ (minSdk 26).

## Build tanpa laptop (dari HP)
1. Buat repo GitHub, upload seluruh isi folder ini.
2. Tab Actions → "Build APK" → Run workflow.
3. Selesai → download artifact `MonvAsisten-APK` → install app-debug.apk.

## Build di Android Studio
File → Open → pilih folder ini → tunggu sync → Run.

## Pakai
1. Buka Monv → aktifkan 5 langkah → "Jalankan Monv".
2. Tap maskot untuk mengembang, ketik perintah (ketik `menu`), tekan GO.
3. HIDE = mengecil jadi bubble & nempel di tepi layar.
